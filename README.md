
# Loot System: Terminal to Interface

## Project Description

This project is a browser-based loot tracking application
created for DEV 109 CA10.

The application allows users to enter loot item names and
values, store them as objects in an array, and calculate
the total value of all collected loot.

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Loops and Conditional Statements

## Features

- Add loot items.
- Validate user input.
- Display collected loot.
- Calculate total loot value.
- Update the interface when a button is clicked.
